# ANFIBIOS CLUB — Instrucciones para iniciar el proyecto



## 1. Preparar el backend (solo la primera vez)
Abrir una terminal en la carpeta principal y ejecuta:

Resumen para recordar
Terminal:	Comando
Primera:	cd backend y luego npm start
Segunda:	npm run dev

Abrr la dirección que muestre Vite (normalmente `http://localhost:5173`).

- Página principal: `http://localhost:5173/`
- Panel administrativo: `http://localhost:5173/admin`

Usar el usuario y la contraseña que configuraste en `backend/.env`.

## 4. Cerrar el proyecto
En cada terminal presiona `Ctrl + C`.
